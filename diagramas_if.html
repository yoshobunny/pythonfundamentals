1if: si pasa algo, hago algo

¿Qué hace este programa? Pregunta cuánta batería tienes. Si tienes 20% o menos, te avisa que conectes el cargador. Si tienes más, no te dice nada de la batería. Al final, siempre muestra "Revisión terminada".

Cómo se lee el diagrama

  1. Empieza en Inicio y lee la batería (paralelogramo verde).
  2. Llega al rombo y hace la pregunta: ¿bateria <= 20?
  3. Si la respuesta es Sí, va a la derecha, muestra "Batería baja, conecta tu cargador" y regresa al camino principal.
  4. Si la respuesta es No, baja directo y se salta el aviso.
  5. Por los dos caminos llega a "Revisión terminada" y termina.

Código (ejemplo1_bateria.py)

print("\n*** Ejemplo 1: if simple, la batería ***\n")

#LEER BATERIA (paralelogramo verde)
#int() convierte el texto a número entero para poder comparar
bateria = int(input("¿Cuánta batería tienes? "))
#Si el usuario escribe 15, ahora bateria vale 15

#LA PREGUNTA (rombo amarillo)
#¿15 es menor o igual que 20? Respuesta: True, entonces SÍ entra
#Si escribiera 80, la respuesta sería False y Python se SALTA lo de adentro
if bateria <= 20:
    #CAMINO DEL SÍ (rectángulo de la derecha)
    #Tiene sangría, por eso solo se ejecuta si la respuesta es True
    print("Batería baja, conecta tu cargador")

#CAMINO PRINCIPAL (rectángulo de abajo)
#No tiene sangría, por aquí pasan el Sí y el No
print("Revisión terminada")

Si un mensaje no sale, no es error: Python tomó el camino del No y se lo saltó.

2if y else: el plan B

¿Qué hace este programa? Pregunta cuántos grados hace. Si hace menos de 15, te dice que te pongas sudadera. Si no (else), te dice que te pongas playera. Al final, siempre te desea buen día.

Cómo se lee el diagrama

  1. Lee la temperatura.
  2. Llega al rombo: ¿temperatura < 15?
  3. Si es Sí, se va a la izquierda (el if): "Hace frío, ponte sudadera".
  4. Si es No, se va a la derecha (el else): "Hace calor, ponte playera".
  5. Los dos caminos se juntan en "¡Que tengas buen día!".

Código (ejemplo2_temperatura.py)

print("\n*** Ejemplo 2: if y else, ¿qué me pongo? ***\n")

#LEER TEMPERATURA (paralelogramo verde)
temperatura = int(input("¿Cuántos grados hace? "))
#Si el usuario escribe 10, ahora temperatura vale 10

#LA PREGUNTA (rombo amarillo)
#¿10 es menor que 15? Respuesta: True, entonces va por el camino del if
if temperatura < 15:
    #CAMINO DEL SÍ (rectángulo azul de la izquierda)
    print("Hace frío, ponte sudadera")
#else significa "si no": aquí entra solo si la respuesta fue False
else:
    #CAMINO DEL NO (rectángulo rosa de la derecha)
    print("Hace calor, ponte playera")

#CAMINO PRINCIPAL: los dos caminos se juntan aquí
print("¡Que tengas buen día!")

Con if y else siempre se toma un camino: nunca los dos y nunca ninguno.

3if, elif y else: varias opciones

¿Qué hace este programa? Muestra los tres tamaños de bebida y pide que elijas uno. Dice qué tamaño elegiste y cuánto cuesta. Si escribes un número que no está en el menú, dice "Opción no válida".

elif significa "si no, entonces pregunta esto otro".

Cómo se lee el diagrama

  1. Lee la opción.
  2. Baja por la izquierda haciendo preguntas, una por una.
  3. En cuanto una respuesta es Sí, sale por la derecha, muestra el tamaño y se va al final. Ya no revisa los rombos de abajo.
  4. Si llega hasta abajo sin ningún Sí, cae en el else: "Opción no válida".
  5. Todos los caminos se juntan en "¡Gracias por tu compra!".

Código (ejemplo3_bebida.py)

print("\n*** Ejemplo 3: if, elif y else, tamaño de tu bebida ***\n")

print("1 = Chico ($55)   2 = Mediano ($70)   3 = Grande ($85)")

#LEER OPCION (paralelogramo verde)
opcion = int(input("Elige tu tamaño: "))
#Si el usuario escribe 2, ahora opcion vale 2

#ROMBO 1: ¿2 es igual a 1? False, baja al siguiente rombo
if opcion == 1:
    print("Chico $55")
#ROMBO 2: ¿2 es igual a 2? True, sale por la derecha y YA NO revisa los de abajo
elif opcion == 2:
    print("Mediano $70")
#ROMBO 3: solo se revisa si los dos anteriores fueron False
elif opcion == 3:
    print("Grande $85")
#ELSE (rectángulo rojo): entra solo si NINGÚN rombo fue True
else:
    print("Opción no válida")

#CAMINO PRINCIPAL: aquí llegan todos los caminos
print("¡Gracias por tu compra!")

2Mediano $70

Es como un mesero: "¿Chico? No. ¿Mediano? Sí". En cuanto dices que sí, deja de preguntar.

4Lunes vs martes

Los dos programas tienen 3 preguntas, pero Python las recorre de forma distinta. Fíjate a dónde va la flecha después de un Sí.

Lunes: varios if separados

Después de un Sí, la flecha regresa al camino y sigue con la siguiente pregunta. Python revisa las 3. Pueden salir varios mensajes.

Martes: if, elif y else

Después de un Sí, la flecha se va directo al final. Python se detiene en la primera que es Sí. Siempre sale un solo mensaje.

Código del lado izquierdo (ejemplo4_celular.py)

print("\n*** Ejemplo 4: varios if separados, estado de mi celular ***\n")

bateria = int(input("¿Cuánta batería tienes? "))
espacio = int(input("¿Cuántos GB libres tienes? "))
notificaciones = int(input("¿Cuántas notificaciones sin leer tienes? "))
print()

#PREGUNTA 1: Python SIEMPRE la revisa
if bateria <= 20:
    print("Batería baja, conecta tu cargador")

#PREGUNTA 2: Python SIEMPRE la revisa, aunque la 1 haya sido True
if espacio < 5:
    print("Poco espacio, borra fotos o apps que no uses")

#PREGUNTA 3: Python SIEMPRE la revisa
if notificaciones > 0:
    print("Tienes", notificaciones, "notificaciones sin leer")
else:
    print("Estás al día, no tienes notificaciones")

print("Revisión terminada")

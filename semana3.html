Python también toma decisiones

Esta semana le vamos a enseñar a la computadora a decidir qué hacer dependiendo de la situación, igual que tú lo haces todos los días.

El if (que significa "si" en inglés) es la instrucción que le permite a un programa tomar decisiones. Le hace una pregunta a la computadora y, dependiendo de la respuesta, ejecuta o no un bloque de código.
Sección 1

Las preguntas que entiende Python

Antes de decidir, hay que saber preguntar.

3.1.1¿Qué es tomar una decisión?

En la vida tomamos decisiones todo el tiempo: si llueve, llevo paraguas; si tengo hambre, como algo; si mi celular tiene poca batería, lo conecto.

Los programas también necesitan decidir qué hacer dependiendo de la situación. Para eso le hacen una pregunta a la computadora, y esa pregunta siempre tiene solo dos respuestas posibles: verdadero (True) o falso (False).

Pregunta: ¿tengo poca batería?
➜
Respuesta: True o False
➜
Acción: aviso o nada

3.1.2Operadores de comparación

Para hacer preguntas, Python usa operadores de comparación:

OperadorSignificadoEjemploResultado
==¿es igual a?15 == 15True
!=¿es diferente de?15 != 18True
>¿es mayor que?10 > 20False
<¿es menor que?10 < 20True
>=¿es mayor o igual que?18 >= 18True
<=¿es menor o igual que?5 <= 3False

¡Ojo! = no es lo mismo que ==

= sirve para guardar un valor en una variable. == sirve para preguntar si dos cosas son iguales. Uno es una flecha que mete el valor, el otro es una pregunta.

Sección 2

Las tres formas del if

De una opción, de dos opciones y de muchas opciones.

3.2.1Forma 1: if simple

Se ejecuta algo solo si la condición es verdadera. Si es falsa, no pasa nada y el programa sigue.

Por ejemplo, cuando la batería de tu celular baja al 20% o menos, te aparece el aviso "Batería baja, conecta tu cargador". Pero si tu batería está al 80%, el celular no te dice nada, simplemente sigue funcionando.

Código 
bateria = 15

if bateria <= 20:
    print("Batería baja, conecta tu cargador")
¿Qué pasa?

Python pregunta: ¿15 es menor o igual a 20? Sí, entonces muestra el mensaje.

Si bateria valiera 80, la respuesta sería no y no aparecería nada.

  • Después de la condición van dos puntos :
  • Lo que está "adentro" del if lleva sangría (4 espacios). Así Python sabe qué instrucciones dependen de la decisión.

Ejemplo 1: Notificación de mensajes

Tu celular te muestra un aviso solo si tienes mensajes nuevos. Si no tienes ninguno, no te avisa.

mensajes_nuevos = 4

if mensajes_nuevos > 0:
    print("Tienes mensajes sin leer")

Ejemplo 2: Récord en un videojuego

El juego te felicita solo si superaste tu récord anterior. ¿620 es mayor que 500? Sí, entonces aparece la felicitación.

record = 500
puntos = 620

if puntos > record:
    print("¡Nuevo récord!")

Ejemplo 3: Clima

Una app te recomienda llevar suéter solo si la temperatura es baja.

temperatura = int(input("¿Qué temperatura hace hoy? "))

if temperatura < 15:
    print("Hace frío, lleva suéter")

3.2.2Forma 2: if con else

En la Forma 1, cuando la condición era falsa no pasaba nada. Pero muchas veces queremos que el programa haga algo en los dos casos: cuando la respuesta es "sí" y cuando es "no".

Para eso existe else, que significa "si no" o "en cualquier otro caso".

  • Si la condición es verdadera, se ejecuta lo que está debajo del if
  • Si la condición es falsa, se ejecuta lo que está debajo del else

Siempre se ejecuta uno de los dos caminos, nunca ambos. Es como llegar a una bifurcación: o vas a la derecha o vas a la izquierda.

Por ejemplo, en el examen del Módulo 2 de Cisco necesitas sacar 70 o más para aprobar. Entonces solo hay dos posibilidades: si sacaste 70 o más, apruebas; si no, repruebas.

Código 
calificacion = int(input("¿Qué calificación sacaste? "))

if calificacion >= 70:
    print("¡Aprobaste!")
else:   # si no
    print("Reprobaste, pero puedes recuperarte")
¿Qué pasa?

Si sacaste 85: ¿85 es mayor o igual a 70? Sí, entonces imprime "¡Aprobaste!" y se salta el else.

Si sacaste 60: ¿60 es mayor o igual a 70? No, entonces se salta el if y entra al else.

Fíjate que el else no lleva condición. No necesita preguntar nada, porque es simplemente "todo lo demás".

Ejemplo 1: Entrar al concierto

En la entrada te escanean el boleto. Si el boleto es válido, entras; si no, no te dejan pasar.

boleto_valido = True

if boleto_valido:
    print("Bienvenido al concierto")
else:   # si no
    print("Boleto no válido, no puedes entrar")

Ejemplo 2: Par o impar

Un número es par si al dividirlo entre 2 no sobra nada. El operador % nos da el residuo de una división (lo vimos en el Módulo 2). Si escribes 8, el residuo es 0 y es par. Si escribes 7, el residuo es 1 y entra al else.

numero = int(input("Escribe un número: "))

if numero % 2 == 0:
    print("Es par")
else:   # si no
    print("Es impar")

3.2.3Forma 3: if, elif y else

A veces la vida no es solo "sí o no", hay más opciones. Por ejemplo, en una calificación no solo importa si aprobaste o no, también importa si fue excelente, buena o regular.

elif es la unión de else + if y significa "si no, entonces pregunta otra cosa". Python revisa las condiciones en orden, de arriba hacia abajo, y entra solo a la primera que sea verdadera. En cuanto encuentra una, ya no revisa las demás.

¿Cuál es la diferencia entre else y elif?

UsoCuántas opcionesEjemplo
if solo1 (pasa algo o no pasa nada)Aviso de batería baja
if + else2 opcionesAprobado o reprobado
if + elif + else3 o más opcionesRango Bronce, Plata, Oro o Leyenda
  • else no lleva condición: es "todo lo demás"
  • elif sí lleva condición: hace una nueva pregunta
  • Puedes poner todos los elif que necesites, pero solo hay un if al inicio y un else al final (el else es opcional)

Por ejemplo, imagina que tu mamá tiene una regla para los videojuegos: según cuántas horas llevas jugando hoy, te dice algo diferente.

  • Si no has jugado nada: "Hoy descansaste del juego"
  • Si llevas 2 horas o menos: "Vas bien, es un tiempo equilibrado"
  • Si llevas 5 horas o menos: "Ya fue bastante, toma un descanso"
  • Si llevas más de 5: "¡Modo maratón! Apágalo y ve a dormir"
horas_jugando = int(input("¿Cuántas horas llevas jugando hoy? "))

if horas_jugando == 0:
    print("Hoy descansaste del juego")
elif horas_jugando <= 2:   # si no, pregunta esto
    print("Vas bien, es un tiempo equilibrado")
elif horas_jugando <= 5:   # si no, pregunta esto otro
    print("Ya fue bastante, toma un descanso")
else:                      # en cualquier otro caso
    print("¡Modo maratón! Apágalo y ve a dormir")

Veamos qué pasa si llevas 4 horas:

  1. ¿4 es igual a 0? No, pasa a la siguiente
  2. ¿4 es menor o igual a 2? No, pasa a la siguiente
  3. ¿4 es menor o igual a 5? Sí, imprime "Ya fue bastante, toma un descanso"
  4. Ya encontró una verdadera, así que ya no revisa el else

Y si llevas 8 horas, ninguna de las tres preguntas es verdadera, entonces entra al else.

¿Por qué importa el orden?

1 hora también es menor o igual a 5. Pero como Python se detiene en la primera verdadera, si llevas 1 hora entra en "Vas bien" y nunca llega a "Ya fue bastante".

Sección 3

Combinando condiciones: and, or, not

Hasta ahora cada if hacía una sola pregunta. Pero en la vida real muchas decisiones dependen de dos cosas a la vez.

3.3.1and significa "y": se tienen que cumplir LAS DOS

Imagina que tus papás te dicen: "Puedes ir a la fiesta si terminaste la tarea Y limpiaste tu cuarto." No basta con una. Si terminaste la tarea pero tu cuarto está desordenado, no vas.

¿Terminaste la tarea?¿Limpiaste el cuarto?¿Vas a la fiesta?
SíSíSí
SíNoNo
NoSíNo
NoNoNo

Con and, solo hay una forma de que sea verdadero: que todo se cumpla.

tarea_terminada = True
cuarto_limpio = False

if tarea_terminada and cuarto_limpio:
    print("Puedes ir a la fiesta")
else:
    print("Todavía no puedes ir")

Aquí imprime "Todavía no puedes ir", porque aunque terminaste la tarea, el cuarto no está limpio.

3.3.2or significa "o": basta con que se cumpla UNA

Ahora imagina la cafetería de la escuela: "Puedes pagar con efectivo O con tarjeta." No necesitas las dos. Con tener cualquiera, ya puedes pagar.

¿Traes efectivo?¿Traes tarjeta?¿Puedes pagar?
SíSíSí
SíNoSí
NoSíSí
NoNoNo

Con or, solo hay una forma de que sea falso: que no se cumpla nada.

efectivo = False
tarjeta = True

if efectivo or tarjeta:
    print("Puedes comprar tu lunch")
else:
    print("No traes con qué pagar")

Aquí imprime "Puedes comprar tu lunch", porque aunque no traes efectivo, sí traes tarjeta.

3.3.3not significa "no": le da la vuelta a la respuesta

not convierte lo verdadero en falso y lo falso en verdadero. Es como decir lo contrario. Por ejemplo: "Si NO está lloviendo, vamos al parque."

lloviendo = False

if not lloviendo:
    print("Vamos al parque")

lloviendo es falso, pero not lo convierte en verdadero, así que sí vamos al parque. Si estuviera lloviendo (True), not lo convertiría en falso y no iríamos.

3.3.4Un truco para recordarlo

  • and es estricto: todos deben decir que sí
  • or es relajado: con que uno diga que sí, es suficiente
  • not es el contreras: siempre dice lo opuesto

3.3.5¿Qué responde Python?

Antes de ver la respuesta, piensen: ¿True o False?

Pregunta 1

True and False

False. Con and las dos tienen que ser verdaderas, y una es falsa.

Pregunta 2

True or False

True. Con or basta con que una sea verdadera.

Pregunta 3

not True

False. not siempre dice lo contrario.

Pregunta 4

Tienes 16 años y boleto. ¿Entras? edad >= 15 and boleto

True. 16 es mayor o igual a 15 y sí tienes boleto, se cumplen las dos.

Cuidado

Errores comunes

Los vas a ver seguido, y está bien. Así se aprende.

  • Olvidar los dos puntos : al final de la condición del if, elif o else
  • No poner sangría en el código que va adentro del if
  • Usar = en lugar de == al comparar
  • Comparar texto con número: input() siempre devuelve texto, por eso usamos int() para convertirlo
  • Mayúsculas y minúsculas: para Python, "Sí" y "sí" son textos diferentes

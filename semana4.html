El ciclo while

while significa "mientras". Repite las instrucciones mientras la respuesta a la pregunta sea Verdadera.

1 Cómo se escribe

Estructura
while condición: instrucciones que se repiten

3 reglas (las mismas del if)

  1. Al final de la línea del while van dos puntos :
  2. Las instrucciones que se repiten van con sangría (4 espacios o Tab).
  3. La condición es una pregunta que da True (Verdadero) o False (Falso).

2 ¿Cómo funciona paso a paso?

1
Python hace la pregunta de la condición.
2
Si la respuesta es Verdadera (True), ejecuta las instrucciones de adentro.
3
Al terminar, regresa a la pregunta y la hace otra vez.
4
Si la respuesta es Falsa (False), se sale del bucle y sigue con lo que está después.

3 ¿En qué se parecen el if y el while?

Se escriben casi igual. La diferencia es cuántas veces hacen la pregunta.

🔹 Con if

Código
# Guardamos el valor 3 en la variable bateria bateria = 3 # Hacemos la pregunta UNA sola vez: ¿la batería es mayor que 0? if bateria > 0: # Si la respuesta es Verdadera (True), se muestra este mensaje print("Viendo un video") # ¿Y si la respuesta es Falsa (False)? # Python se salta el print y sigue con lo que esté después del if. # Aquí no hay nada más, así que el programa termina.
Salida en pantalla
Viendo un video

El if pregunta una sola vez.

🔁 Con while

Código
# Guardamos el valor 3 en la variable bateria bateria = 3 # Hacemos la pregunta: ¿la batería es mayor que 0? # Mientras la respuesta sea Verdadera (True), se repite lo de adentro while bateria > 0: # Se muestra el mensaje print("Viendo un video") # Le restamos 1 a la batería (esto es LO QUE CAMBIA) bateria = bateria - 1 # Aquí Python REGRESA a la pregunta del while # Cuando la respuesta es Falsa (False), sale del while y termina
Salida en pantalla
Viendo un video Viendo un video Viendo un video

El while pregunta una y otra vez.

👉 Piénsalo así: el while es un if que se repite.

⚠️ El bucle infinito

El error más común con el while.

Código
bateria = 3 while bateria > 0: print("Viendo un video") # ❌ Olvidamos restarle 1 a la batería. # bateria SIEMPRE vale 3, la pregunta SIEMPRE es True # y el programa imprime para siempre.

Nunca cambiamos la batería: siempre vale 3 y la pregunta siempre da True. Es como si Strange nunca tuviera la Gema del Tiempo.

🛑 ¿Cómo lo detengo? Presiona Ctrl + C en la terminal de VS Code.
👉 Pregunta para revisar cualquier while: "¿Qué cambia adentro del bucle que algún día hará que la pregunta dé False?" Si no encuentras nada, tienes un bucle infinito.

5 Contraseña con 3 intentos 🔐

Como en tu celular o en la app del banco: si te equivocas 3 veces, se bloquea.

Código
# 1. Guardamos la contraseña correcta correcta = "cafe123" # 2. Empezamos con 0 intentos intentos = 0 # 3. Mientras lleve menos de 3 intentos, se repite while intentos < 3: # 4. Pedimos la contraseña escrita = input("Escribe tu contraseña: ") # 5. ¿La que escribió es IGUAL a la correcta? if escrita == correcta: print("✅ Bienvenido") # 6. Ya entró: break lo saca del while en este momento break else: # 7. Se equivocó: sumamos 1 intento y avisamos intentos = intentos + 1 print("❌ Incorrecta. Llevas", intentos, "intentos") # 8. Ya fuera del while: ¿se acabaron los intentos? if intentos == 3: print("🔒 Cuenta bloqueada")
Corrida 1: acierta en el segundo intento
Escribe tu contraseña: hola ❌ Incorrecta. Llevas 1 intentos Escribe tu contraseña: cafe123 ✅ Bienvenido

El break lo saca del while aunque intentos < 3 todavía sea True.

Corrida 2: falla 3 veces
Escribe tu contraseña: hola ❌ Incorrecta. Llevas 1 intentos Escribe tu contraseña: 1234 ❌ Incorrecta. Llevas 2 intentos Escribe tu contraseña: cafe ❌ Incorrecta. Llevas 3 intentos 🔒 Cuenta bloqueada

Nunca hubo break. El while terminó porque intentos < 3 dio False.

👉 Un while con break tiene dos salidas: el break, o que la pregunta dé False.

Repaso

Repaso del while

  • Un bucle (loop) es algo que se repite hasta que pasa algo que lo detiene.
  • El while ("mientras") repite mientras la respuesta sea Verdadera (True). Lo usamos cuando no sabemos cuántas veces se va a repetir.
  • Si nada cambia adentro, el bucle es infinito.
  • break nos saca del bucle en ese momento.
🤔 Pero... ¿y si sí sé cuántas veces se repite? Por ejemplo: "haz 10 sentadillas". Para eso existe el for.

El ciclo for

for significa "para cada". Toma una colección de cosas y repite las instrucciones una vez por cada cosa.

1 Cómo se escribe

Estructura
for variable in colección: instrucciones que se repiten

Las partes

  • for: "para cada".
  • variable: un nombre que tú eliges (cancion, amigo, vuelta). En cada vuelta guarda una cosa distinta de la colección.
  • in: "en" o "de".
  • colección: las cosas que se van a recorrer (unos números con range, un texto o una colección de canciones).
  • Igual que el if y el while: dos puntos : al final y sangría en lo que se repite.
🗣️ Léelo en voz alta: for cancion in playlist: se lee "para cada canción de la playlist".

2 ¿Cómo funciona paso a paso?

1
El for toma la primera cosa de la colección y la guarda en la variable.
2
Ejecuta las instrucciones de adentro.
3
Toma la siguiente cosa, la guarda en la variable y vuelve a ejecutar las instrucciones.
4
Cuando ya no quedan cosas, se sale del for y sigue con lo que está después.
✨ La gran ventaja: en el while tú tenías que cambiar la variable (bateria = bateria - 1). En el for, la variable cambia sola en cada vuelta. Por eso es más difícil hacer un bucle infinito con for.

range(): repetir X veces

range() genera una fila de números para que el for sepa cuántas vueltas dar.

Cómo se escribeQué números da¿Para qué?
range(5)0, 1, 2, 3, 4Repetir 5 veces. ¡Empieza en 0!
range(1, 6)1, 2, 3, 4, 5Empezar en 1. Se detiene antes del 6
range(0, 10, 2)0, 2, 4, 6, 8Ir de 2 en 2
range(3, 0, -1)3, 2, 1Ir hacia atrás (cuenta regresiva)
⚠️ range nunca incluye el último número. Es como cuando dices "llego antes de las 6": nunca llegas a las 6. range(1, 6) llega hasta el 5.

¿while o for?

Las mismas 5 sentadillas, escritas de las dos formas.

Con while
# 1. Nosotros creamos el contador repeticion = 1 # 2. Nosotros escribimos la pregunta while repeticion <= 5: print("Sentadilla número", repeticion) # 3. Nosotros cambiamos el contador repeticion = repeticion + 1
Con for
# El for hace los 3 pasos por nosotros: # crea el contador, pregunta y lo cambia for repeticion in range(1, 6): print("Sentadilla número", repeticion)
👉 Los dos muestran lo mismo. El for es más corto porque crea, pregunta y cambia el contador por ti.

break y continue dentro del for

Ya conoces el break. Ahora conoce a su compañero: el continue.

🛑 break

"Ya encontré lo que buscaba, me salgo". Como dejar de buscar en los cajones cuando encuentras tus llaves.

⏭️ continue

"Esta vuelta me la salto, pero sigo con la siguiente". Como saltar la canción que no te gusta.

10 Extra: el else del for 👟

Un for puede llevar else. Ese bloque se ejecuta solo si el for terminó sin break.

Código
# Guardamos el modelo que busca el cliente buscado = "Vans" # Revisamos cada modelo del inventario for tenis in ["Air Max", "Jordan 1", "Converse"]: # ¿Este es el que busca? if tenis == buscado: print("✅ Sí lo tenemos") break else: # El else del for SOLO se ejecuta si el for terminó sin break # (es decir, si revisamos todo y nunca lo encontramos) print("❌ No tenemos", buscado)
Salida en pantalla
❌ No tenemos Vans

Revisó los 3 modelos y nunca encontró los Vans, así que nunca hubo break y entró al else.

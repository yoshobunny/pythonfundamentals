3Comentarios

Todo lo que va después de # es una nota para humanos. Python la ignora. En esta actividad son obligatorios para nosotros porque son las notas para saber qué hace el código.

# Esto es un comentario, Python no lo ejecuta
print("Esto sí se ejecuta")

4¿Qué es una variable?

Una cajita con nombre donde guardamos un dato.
El signo = no significa "es igual a", significa "guarda esto aquí".
El doble == ese sí es el igual al que conocemos de clase de matemáticas.

artista = "Peso Pluma"
seguidores = 1500 # aquí se asigna el valor de 1500 a la variable seguidores
x == 12           # este sí significa el igual de clase de mate
✅ Sí se puede❌ No se puede
edad_mascota, vida22vida (no empieza con número)
Guion bajo para separar palabrasedad mascota (no debe tener espacios porque son dos variables, edad y mascota)
Letras sin acento, números y _año, canción (evita ñ y acentos)
Python distingue mayúsculas: Vida y vida son cajitas distintas.

6f-strings

Con una f antes de las comillas metes variables dentro del texto usando { }.

mascota = "Michi"
edad = 3
print(f"Mi gato {mascota} tiene {edad} años")

horas = 41.666666
print(f"Son {horas:.1f} horas")   # Como usamos .1f redondea a 1 decimal, por eso es 41.7 horas
:.1f muestra un decimal y :.2f dos decimales (ideal para dinero).

7¿Qué es un operador?

Un símbolo que le dice a Python qué cálculo hacer.

OperadorQué haceEjemplo
+Suma10 + 3 = 13
-Resta10 - 3 = 7
*Multiplicación10 * 3 = 30
/División (da decimal)10 / 3 = 3.33
//División entera10 // 3 = 3
%Residuo (lo que sobra)10 % 3 = 1
**Potencia2 ** 3 = 8
# Aquí aplican las reglas de matemáticas PEMDAS (Paréntesis, Exponentes, Mult, Div, Suma, Resta)
print(2 + 3 * 4)     # 14 (primero multiplica)
print((2 + 3) * 4)   # 20 (primero el paréntesis)

8// y %: minutos y segundos

Nadie dice "3.58 minutos". Decimos "3 minutos con 35 segundos".

segundos_totales = 215
minutos = segundos_totales // 60    # 3 minutos completos
segundos = segundos_totales % 60    # sobran 35 segundos
print(f"{minutos} minutos con {segundos} segundos")

9Variables que cambian

Python primero calcula lo que está a la derecha del = y después lo guarda en la cajita.

vida = 100
nueva_vida = vida - 25   # vida vale 100, y nueva_vida vale 100 - 25, que es 75

10input(): el programa te pregunta

nombre = input("¿Cómo te llamas? ")
print(f"Hola, {nombre}")
input() SIEMPRE devuelve texto. Si escribes 2 y 2, "2" + "2" da "22" 😱
edad = int(input("Edad: "))          # int() para enteros
precio = float(input("Precio: $"))   # float() para decimales

Ejercicio 1 · Liberación de embarque en aduana

📖 Historia

Logística te pide un programa para saber si un embarque ya puede salir de la aduana. El agente aduanal revisa cuatro requisitos y no deja pasar ningún embarque al que le falte algo. Si el embarque se detiene, Logística necesita saber exactamente qué falta para resolverlo rápido.

📋 Reglas de negocio que se deben cumplir

  1. El embarque debe traer la factura comercial.
  2. El embarque debe traer el pedimento de importación.
  3. Los impuestos deben estar pagados.
  4. La mercancía debe coincidir con lo declarado.
  5. Si se cumplen los cuatro requisitos, el embarque se libera.
  6. Si el embarque se libera y vale más de $100,000 dólares, hay que avisar al gerente de logística.
  7. Si falta cualquier requisito, el embarque se detiene y se debe mostrar la lista de lo que falta y cuántos requisitos faltan.

🎯 Tu programa debe

  1. Preguntar los cuatro requisitos (si/no) y el valor de la mercancía.
  2. Convertir cada respuesta en True o False.
  3. Usar and para revisar los cuatro requisitos en un solo if.
  4. Usar and otra vez para el aviso de alto valor.
  5. Usar not para mostrar, uno por uno, los requisitos que no se cumplieron.
  6. Contar cuántos requisitos faltan con un contador.

💻 Código

print("Ejercicio 1: Liberación de embarque en aduana") print("Nombre: Escribe aquí tu nombre completo") print("Matrícula: Escribe aquí tu matrícula") print() # Preguntamos por los 4 documentos y revisiones de la aduana factura = input("¿Tienes la factura comercial? (si/no): ") valor = float(input("Valor de la mercancía en dólares: ")) # Convertimos cada respuesta en True o False # Si escribió "si" se guarda True; si escribió otra cosa se guarda False tiene_factura = factura == "si" tiene_pedimento = pedimento == "si" impuestos_pagados = impuestos == "si" mercancia_ok = coincide == "si" print() print("===== RESULTADO DE LA ADUANA =====") # and: los CUATRO requisitos se deben cumplir al mismo tiempo if tiene_factura and tiene_pedimento and impuestos_pagados and mercancia_ok: print("✅ Embarque liberado. Puede salir de la aduana.") # and: liberado Y de alto valor: hay que avisarle al gerente if valor > 100000: print("📢 Embarque de alto valor: avisa al gerente de logística.") else: print("🛑 Embarque detenido. Faltan estos requisitos:") # Contamos cuántos requisitos faltan faltantes = 0 # not: revisamos uno por uno cuál NO se cumplió if not tiene_factura: print(" - Factura comercial") faltantes = faltantes + 1 if not tiene_pedimento: print(" - Pedimento de importación") faltantes = faltantes + 1 if not impuestos_pagados: print(" - Pago de impuestos") faltantes = faltantes + 1 if not mercancia_ok: print(" - La mercancía no coincide con lo declarado") faltantes = faltantes + 1 print("Total de requisitos pendientes:", faltantes)

Ejercicio 2 · ¿Quién paga el flete y el seguro?

📖 Historia

Ventas cierra contratos con clientes de otros países usando Incoterms, que son reglas internacionales que dicen quién paga cada cosa. Te piden un programa que, con los datos del contrato, diga quién paga el flete internacional, quién contrata el seguro y cuánto costaría el seguro.

📋 Reglas de negocio que se deben cumplir

  1. Solo se aceptan los Incoterms EXW, FOB, CIF, CIP y DAP. Si escriben otro, el programa avisa que no es válido.
  2. Con EXW o FOB, el flete internacional lo paga el comprador. Con CIF, CIP o DAP lo paga el vendedor.
  3. Con CIF o CIP, el seguro lo contrata el vendedor. Con los demás, lo decide el comprador.
  4. Si la mercancía es frágil o viaja por transporte MARITIMO, el seguro cuesta el 2% del valor.
  5. En cualquier otro caso, el seguro cuesta el 1% del valor.

🎯 Tu programa debe

  1. Pedir el Incoterm y el transporte en MAYÚSCULAS, el valor de la mercancía y si es frágil.
  2. Usar not con or para detectar un Incoterm que no es válido.
  3. Usar or para decidir quién paga el flete.
  4. Usar or para decidir quién contrata el seguro y qué porcentaje se cobra.
  5. Mostrar un resumen del contrato.

💻 Código

print("Ejercicio 2: ¿Quién paga el flete y el seguro?") print("Nombre: Escribe aquí tu nombre completo") print("Matrícula: Escribe aquí tu matrícula") print() # Pedimos los datos del contrato incoterm = input("Escribe el Incoterm en MAYÚSCULAS (EXW, FOB, CIF, CIP, DAP): ") valor = float(input("Valor de la mercancía en dólares: ")) transporte = input("Transporte en MAYÚSCULAS (MARITIMO, AEREO, TERRESTRE): ") fragil = input("¿La mercancía es frágil? (si/no): ") # Convertimos la respuesta en True o False es_fragil = fragil == "si" print() print("===== RESUMEN DEL CONTRATO =====") # not + or: si NO es ninguno de los 5 Incoterms, el dato está mal if not (incoterm == "EXW" or incoterm == "FOB" or incoterm == "CIF" or incoterm == "CIP" or incoterm == "DAP"): print("❌ Incoterm no válido. Revisa que esté en MAYÚSCULAS.") else: # or: con EXW o FOB, el flete internacional lo paga el COMPRADOR if incoterm == "EXW" or incoterm == "FOB": print("🚚 Flete internacional: lo paga el COMPRADOR.") else: print("🚚 Flete internacional: lo paga el VENDEDOR.") # or: con CIF o CIP, el seguro lo contrata el VENDEDOR if incoterm == "CIF" or incoterm == "CIP": # or: si es frágil O va por barco, el riesgo es mayor if es_fragil or transporte == "MARITIMO": porcentaje = 2 else: porcentaje = 1 seguro = valor * porcentaje / 100 print("✅ Seguro: lo contrata el VENDEDOR.") print("Porcentaje del seguro: ", porcentaje, "%", sep="") print("Costo estimado del seguro: $", seguro, sep="") else: print("📦 Seguro: NO lo contrata el vendedor. Lo decide el COMPRADOR.")

Ejercicio 3 · ¿Se puede exportar el producto?

📖 Historia

Algunos productos (como ciertos químicos o medicamentos) están en una lista de restringidos y no se pueden exportar sin un permiso especial vigente. Además, hay países destino con restricciones comerciales. Cumplimiento te pide un programa que decida si un producto se puede enviar y, si no, que explique el motivo.

📋 Reglas de negocio que se deben cumplir

  1. Un permiso especial solo es válido si la empresa lo tiene y además está vigente.
  2. Si el producto NO está restringido, cumple la primera condición.
  3. Si el producto está restringido, cumple la primera condición solo si tiene un permiso válido.
  4. Además, el país destino NO debe tener restricciones comerciales.
  5. Si el producto se puede exportar, es restringido y pesa más de 1000 kg, necesita inspección previa.
  6. Si no se puede exportar, se muestra el motivo: destino con restricciones, falta de permiso o permiso vencido.

🎯 Tu programa debe

  1. Pedir el producto, las cuatro respuestas de si/no y los kilos.
  2. Crear la variable permiso_valido con and.
  3. Escribir la condición principal combinando not, or y and con paréntesis.
  4. Usar and para el aviso de inspección.
  5. Usar if, elif para explicar el motivo cuando no se puede exportar.

(si/no): ") kilos = float(input("¿Cuántos kilos vas a enviar?: ")) # Convertimos las respuestas en True o False restringido = respuesta1 == "si" tiene_permiso = respuesta2 == "si" permiso_vigente = respuesta3 == "si" destino_restringido = respuesta4 == "si" # Un permiso solo sirve si existe Y está vigente permiso_valido = tiene_permiso and permiso_vigente print() print("===== REVISIÓN DE CUMPLIMIENTO =====") # Se exporta si: (NO está restringido O tiene permiso válido) Y el destino NO tiene restricciones if (not restringido or permiso_valido) and not destino_restringido: print("✅", producto, "se puede exportar.") # and: restringido Y más de 1000 kilos: necesita inspección if restringido and kilos > 1000: print("🔍 Por ser restringido y pesar más de 1000 kg, necesita inspección previa.") else: print("🛑", producto, "NO se puede exportar.") # Explicamos el motivo if destino_restringido: print("Motivo: el país destino tiene restricciones comerciales.") elif not tiene_permiso: print("Motivo: el producto está restringido y no hay permiso especial.") elif not permiso_vigente: print("Motivo: el permiso especial está vencido. Ejercicio 4 · Semáforo de revisión aduanal

📖 Historia

Al llegar a la aduana, cada embarque recibe un semáforo: verde pasa directo y rojo se revisa a mano. Comercio Exterior quiere predecir qué color le va a tocar a cada embarque, cuántos días se va a quedar y cuánto se va a pagar de almacenaje.

📋 Reglas de negocio que se deben cumplir

  1. Si los documentos NO están completos, el semáforo siempre es ROJO, aunque la empresa esté certificada.
  2. Si el embarque vale más de $50,000 dólares o es la primera vez que la empresa importa, es candidato a revisión.
  3. Un candidato a revisión pasa a ROJO solo si la empresa NO está certificada como confiable.
  4. En cualquier otro caso, el semáforo es VERDE.
  5. ROJO tarda 3 días. Si además la mercancía es perecedera, se pide revisión prioritaria y tarda 1 día. VERDE tarda 0 días.
  6. Cada día en la aduana cuesta $500 de almacenaje.

🎯 Tu programa debe

  1. Pedir el valor y las cuatro respuestas de si/no.
  2. Combinar not, or y and en un solo if, usando paréntesis.
  3. Revisar si es perecedero dentro del semáforo rojo.
  4. Calcular y mostrar los días y el costo de almacenaje.

Ejercicio 5 · Cálculo de impuestos con el T-MEC

📖 Historia

Gracias al T-MEC (el tratado entre México, Estados Unidos y Canadá), algunos productos pagan 0% de arancel al importarse. Importaciones te pide calcular el arancel, el IVA y el total de cada mercancía, y avisar cuando la empresa pudo haber ahorrado dinero. Esta vez tú escribes las partes que faltan.

📋 Reglas de negocio que se deben cumplir

  1. Si el país de origen es MEXICO, la mercancía es nacional y no paga impuestos de importación.
  2. El trato preferencial aplica si la mercancía viene de ESTADOS UNIDOS o de CANADA, y además tiene certificado de origen.
  3. Si aplica, el arancel es 0%. Si no aplica, se cobra el arancel general del 15% (cifra para el ejercicio).
  4. Impuesto del arancel = valor × arancel ÷ 100.
  5. IVA = (valor + impuesto del arancel) × 16 ÷ 100.
  6. Total = valor + impuesto del arancel + IVA.
  7. Si la mercancía viene de ESTADOS UNIDOS o CANADA pero NO tiene certificado, avisar cuánto se habría ahorrado en arancel.

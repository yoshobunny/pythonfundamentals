B

Reglas del sistema (detalle)

Las condiciones que el sistema revisa antes de hacer algo. Escríbelas en tu Word adaptadas a tu proyecto.

RS01 Campos completos y clave nueva (Altas)

  • Condición 1: todos los campos están llenos.
  • Condición 2: la clave NO existe en la lista.
  • Se cumple cuando: Condición 1 Y Condición 2.
  • Si se cumple: pasa a la revisión de RS02.
  • Si no se cumple: "Llena todos los campos" o "Esa clave ya existe".
🔑 Como la clave es automática, desde el formulario la Condición 2 siempre es Verdadera. En tu tabla de verdad sí llenas los 4 renglones, pero la captura de "no se cumple" la haces con un campo vacío.

RS02 Datos numéricos válidos (Altas y Cambios)

  • Condición 1: el dato es un número entero: solo dígitos, sin letras, símbolos, signo ni punto decimal.
  • Condición 2: el dato es mayor que 0.
  • Se cumple cuando: Condición 1 Y Condición 2. Aplica a precio, cantidad, edad, puntos, etc.
  • Si se cumple: el dato se acepta.
  • Si no se cumple: "Escribe un número mayor que 0".

RS03 Confirmación de alta (Altas)

  • Condición 1: RS01 y RS02 se cumplieron.
  • Condición 2: el usuario confirma que quiere guardar.
  • Se cumple cuando: Condición 1 Y Condición 2.
  • Si se cumple: "Registro guardado con la clave ___".
  • Si no se cumple: "Alta cancelada".

RS04 Baja de un registro (Bajas)

  • Condición 1: la clave existe en la lista.
  • Condición 2: el usuario confirma la baja.
  • Se cumple cuando: Condición 1 Y Condición 2.
  • Si se cumple: "Registro eliminado".
  • Si no se cumple: "Ese registro no existe" o "Baja cancelada".

RS05 Cambio de un dato (Cambios)

  • Condición 1: la clave existe en la lista.
  • Condición 2: el nuevo valor NO está vacío.
  • Condición 3: el nuevo valor es válido (si es número, cumple RS02).
  • Se cumple cuando: Condición 1 Y Condición 2 Y Condición 3.
  • Si se cumple: "Registro actualizado".
  • Si no se cumple: el mensaje del error que corresponda.

RS06 Búsqueda (Consultas)

  • Condición 1: la clave del registro coincide con lo buscado.
  • Condición 2: el otro campo del registro coincide con lo buscado.
  • Se cumple cuando: Condición 1 O Condición 2.
  • Si se cumple: el registro aparece en los resultados.
  • Si no se cumple: si ningún registro cumple: "No hay resultados".

RS07 Lista con registros (Imprimir)

  • Condición: la lista NO está vacía.
  • Si se cumple: se muestra la tabla con todos los registros.
  • Si no se cumple: "No hay registros".

RS08 Alertas de cantidad (Imprimir y Consultas)

  • Condición 1: la cantidad es mayor que 0.
  • Condición 2: la cantidad es menor o igual a 3.
  • Se cumple cuando: "Por agotarse": Condición 1 Y Condición 2. "Agotado": la cantidad es igual a 0.
  • Si se cumple: se muestra la alerta junto al registro.
  • Si no se cumple: no se muestra alerta.
💡 Como RS02 no deja guardar una cantidad de 0, el registro "Agotado" debe venir desde tus datos iniciales: de tus 8 registros, pon al menos 1 con cantidad 0 y al menos 1 con cantidad de 1 a 3. RS08 aplica a los proyectos que manejan cantidades (stock, piezas, boletos disponibles). Si tu proyecto no tiene cantidades, cámbiala por una regla parecida de tu negocio.

RS09 Salir del sistema (Salir)

  • Condición: el usuario confirma que quiere salir.
  • Si se cumple: el sistema se cierra.
  • Si no se cumple: regresa al menú principal.

RS10 Regla propia de tu negocio

  • La escribe cada pareja, con mínimo 2 condiciones unidas con AND, OR o NOT.
  • Mismo formato que las demás: condiciones, cuándo se cumple, qué pasa si se cumple y mensaje si no se cumple.
  • Ejemplo: "Una mascota se puede adoptar si está disponible Y fue vacunada".

🧰 Herramientas que vas a usar

Leer lo que escribió el usuario

.get() lee la caja y .strip() quita espacios de más.

Ejemplo
nombre = caja_nombre.get().strip()

¿Es un número?

isdigit() es True solo si el texto tiene puros dígitos (sin letras, signo - ni punto decimal). Para guardarlo como número usa int().

Ejemplo
if precio.isdigit(): precio = int(precio)

Mensajes de error y confirmación

showerror muestra un error y askyesno pregunta Sí o No (regresa True o False).

Ejemplo
messagebox.showerror("Error", "Llena todos los campos.", parent=ventanita) confirma = messagebox.askyesno("Confirmar", "¿Guardar el registro?", parent=ventanita)

Guardar el registro

append agrega el registro nuevo al final de la lista.

Ejemplo
registros.append([clave_nueva, nombre, categoria, int(precio), int(cantidad)])

🧰 Herramientas que vas a usar

¿Existe la clave?

buscar_posicion regresa en qué lugar está el registro, o -1 si no existe.

Ejemplo
posicion = buscar_posicion(caja_clave.get().strip()) if posicion == -1: messagebox.showerror("Error", "Ese registro no existe.", parent=ventanita)

Eliminar y cambiar

del borra el registro de esa posición. Para cambiar un campo, se asigna el nuevo valor en esa posición y ese campo.

Ejemplo
del registros[posicion] registros[posicion][campo] = nuevo_valor

Cerrar el sistema

ventana.destroy() cierra la ventana principal.

Ejemplo
if messagebox.askyesno("Salir", "¿Seguro que quieres salir?"): ventana.destroy()

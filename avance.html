Martes 27

Ejercicios del martes

if, elif y else: cuando hay más de dos opciones.

!¿Qué cambia hoy?

El lunes cada if era una pregunta independiente: Python las revisaba todas y podían salir varios mensajes al mismo tiempo (por ejemplo, batería baja y poco espacio).

Hoy usamos elif, que significa "si no, entonces pregunta esto otro". Con if / elif / else Python revisa las preguntas en orden y se detiene en la primera que sea True. Por eso siempre sale un solo resultado.

Tip

Antes de correr cada prueba, adivina qué mensaje va a salir. Si aciertas, ya entendiste la lógica.

MARTES · EJERCICIO 9

Tamaño de tu bebida

¿De qué se trata?

En una tienda de bebidas (frappés, tés, bubble tea) hay tres tamaños. El programa muestra el menú, el usuario elige un número y el programa le dice qué tamaño eligió y cuánto cuesta.

La lógica del programa

Solo puedes elegir un tamaño (no puedes pedir chico y grande en el mismo vaso). Por eso usamos elif, que significa "si no, entonces pregunta esto otro". Python revisa las preguntas en orden y se detiene en la primera que dé True. Las demás ya ni las revisa.

OrdenPreguntaSi es SÍ (True)Si es NO (False)
1¿Escribió 1?Chico, $55, y terminaPasa a la pregunta 2
2¿Escribió 2?Mediano, $70, y terminaPasa a la pregunta 3
3¿Escribió 3?Grande, $85, y terminaSe va al else
4else (ninguna de las anteriores)"Opción no válida"
Es como un mesero tomando tu pedido: "¿chico? No. ¿Mediano? No. ¿Grande? Sí". En cuanto dices que sí, deja de preguntar. Siempre sale un solo mensaje, nunca dos y nunca ninguno.

Pasos

  1. Mostrar el menú con los tres tamaños y sus precios.
  2. Pedir al usuario que escriba 1, 2 o 3.
  3. Revisar en orden qué número escribió y mostrar el tamaño y el precio.
  4. Si escribió otro número, mostrar "Opción no válida".

Código

print("\n*** Nombre 1:    Matricula:     ***")
print("*** Nombre 2:    Matricula:     ***\n")

print("*** Ejercicio 9 Tamaño de tu bebida ***")

#Mostramos el menú para que el usuario sepa qué puede elegir
print("\n===== MENÚ DE TAMAÑOS =====")
print("1 = Chico   ($55)")
print("2 = Mediano ($70)")
print("3 = Grande  ($85)")

#input() pregunta y guarda la respuesta como TEXTO
#int() la convierte a número entero para poder compararla con 1, 2 y 3
opcion = int(input("\n¿Qué tamaño quieres? Escribe 1, 2 o 3: "))
#Si el usuario escribe 2, ahora opcion vale 2

#PREGUNTA 1: ¿2 es igual a 1? Respuesta: False, entonces pasa a la siguiente pregunta
if opcion == 1:
    print("Elegiste tamaño CHICO, son $55")

#PREGUNTA 2: ¿2 es igual a 2? Respuesta: True, entonces muestra este mensaje
#y Python YA NO revisa las preguntas de abajo
elif opcion == 2:
    print("Elegiste tamaño MEDIANO, son $70")

#PREGUNTA 3: solo se revisa si las dos anteriores fueron False
elif opcion == 3:
    print("Elegiste tamaño GRANDE, son $85")

#else: entra aquí solo si NINGUNA pregunta fue True (escribió 4, 7, 0, etc.)
else:
    print("Opción no válida, elige 1, 2 o 3")

#Esta línea no tiene sangría, no pertenece al if, por eso se muestra siempre
print("\n¡Gracias por tu compra!")

Nivel de influencer

¿De qué se trata?

En redes sociales, el nivel de una cuenta depende de cuántos seguidores tiene. El programa pide el número de seguidores y dice en qué nivel está:

  • Menos de 1,000: Principiante
  • De 1,000 a 9,999: Microinfluencer
  • De 10,000 a 99,999: Influencer
  • 100,000 o más: Celebridad digital

La lógica del programa

Python revisa las preguntas de arriba hacia abajo y se detiene en la primera que sea True. El truco es que cada pregunta ya sabe lo que respondieron las de arriba: si llegamos a la pregunta 2, es porque la 1 fue False, o sea que ya sabemos que tiene 1,000 o más. Por eso no hay que volver a preguntarlo.

OrdenPreguntaSi es SÍ (True)Si es NO (False)
1¿Tiene menos de 1,000?Principiante, y terminaYa sabemos que tiene 1,000 o más. Pasa a la 2
2¿Tiene menos de 10,000?Microinfluencer, y terminaYa sabemos que tiene 10,000 o más. Pasa a la 3
3¿Tiene menos de 100,000?Influencer, y terminaSe va al else
4elseCelebridad digital
El orden importa. Si pusieras primero seguidores < 100000, alguien con 500 seguidores saldría como Influencer, porque 500 también es menor que 100,000 y Python se detiene ahí.

Pasos

  1. Pedir el nombre de usuario y el número de seguidores.
  2. Revisar en orden, de menor a mayor, en qué nivel está.
  3. Mostrar el nivel.

Código

print("\n*** Nombre 1:    Matricula:     ***")
print("*** Nombre 2:    Matricula:     ***\n")

print("*** Ejercicio 10 Nivel de influencer ***")

#input() guarda texto; el usuario es texto, así que no lo convertimos
usuario = input("\nTu usuario: @")
#int() convierte a número entero para poder comparar
seguidores = int(input("¿Cuántos seguidores tienes? "))
#Si el usuario escribe 25000, ahora seguidores vale 25000

print(f"\n===== NIVEL DE @{usuario} =====")

#PREGUNTA 1: ¿25000 es menor que 1000? Respuesta: False, pasa a la siguiente
if seguidores < 1000:
    print("Nivel: Principiante")

#PREGUNTA 2: si llegamos aquí, YA SABEMOS que tiene 1000 o más
#¿25000 es menor que 10000? Respuesta: False, pasa a la siguiente
elif seguidores < 10000:
    print("Nivel: Microinfluencer")

#PREGUNTA 3: si llegamos aquí, YA SABEMOS que tiene 10000 o más
#¿25000 es menor que 100000? Respuesta: True, muestra el mensaje y TERMINA
elif seguidores < 100000:
    print("Nivel: Influencer")

#else: si ninguna fue True, tiene 100000 o más
else:
    print("Nivel: Celebridad digital")

Mensaje según tu calificación

¿De qué se trata?

Ya hiciste el examen de Cisco (de 0 a 100). El programa pide la calificación y muestra un mensaje:

  • Mayor a 100 o menor a 0: "Calificación no válida"
  • 90 o más: "¡Excelente! Eres crack"
  • De 80 a 89: "Muy bien"
  • De 70 a 79: "Aprobaste, pero puedes mejorar"
  • Menos de 70: "Reprobaste, ¡a estudiar!"

La lógica del programa

Aquí lo nuevo es que primero revisamos si el dato es válido. Si alguien escribe 150, no queremos que le diga "Excelente". Por eso las preguntas de "no válida" van hasta arriba: si una es True, Python se detiene ahí y ya no revisa las demás.

OrdenPreguntaSi es SÍ (True)Si es NO (False)
1¿Es mayor a 100?"Calificación no válida"Pasa a la 2
2¿Es menor a 0?"Calificación no válida"Pasa a la 3
3¿Es 90 o más?"¡Excelente! Eres crack"Pasa a la 4
4¿Es 80 o más?"Muy bien"Pasa a la 5
5¿Es 70 o más?"Aprobaste, pero puedes mejorar"Se va al else
6else"Reprobaste, ¡a estudiar!"
Ahora vamos de mayor a menor (90, 80, 70). También funciona, siempre que respetes el orden. Mañana veremos or, que sirve para juntar las preguntas 1 y 2 en una sola.

Pasos

  1. Pedir la calificación del examen.
  2. Revisar primero si la calificación es válida (entre 0 y 100).
  3. Si es válida, revisar de mayor a menor qué mensaje le toca.
  4. Mostrar el mensaje.

Código

print("\n*** Nombre 1:    Matricula:     ***")

#Si el usuario escribe 85, ahora calificacion vale 85

print("\n===== RESULTADO =====")

#PRIMERO revisamos que la calificación sea válida
#¿85 es mayor que 100? False, pasa a la siguiente
if calificacion > 100:
    print("Calificación no válida, debe ser de 0 a 100")

#¿85 es menor que 0? False, pasa a la siguiente
elif calificacion < 0:
    print("Calificación no válida, debe ser de 0 a 100")

#Si llegamos aquí, YA SABEMOS que la calificación es válida
#¿85 es mayor o igual que 90? False, pasa a la siguiente
elif calificacion >= 90:
    print("¡Excelente! Eres crack")

#¿85 es mayor o igual que 80? True, muestra el mensaje y TERMINA
elif calificacion >= 80:
    print("Muy bien")

#Ya sabemos que es menor que 80
elif calificacion >= 70:
    print("Aprobaste, pero puedes mejorar")

#else: es menor que 70
else:
    print("Reprobaste, ¡a estudiar!")

Costo de envío

¿De qué se trata?

Pediste algo en una app de entregas y el costo de envío depende de qué tan lejos vives:

  • 3 km o menos: envío gratis
  • Más de 3 y hasta 10 km: $39
  • Más de 10 y hasta 20 km: $69
  • Más de 20 km: no hay envío, lo recoges en tienda (envío $0)

La lógica del programa

Esta vez, en lugar de solo mostrar un mensaje, adentro de cada opción guardamos un valor en la variable costo_envio. Solo una opción se ejecuta, así que la variable termina con un solo valor. Al final, afuera del if, sumamos el pedido más el envío.

OrdenPreguntaSi es SÍ (True)Si es NO (False)
1¿Vive a 3 km o menos?costo_envio = 0Pasa a la 2
2¿Vive a 10 km o menos?costo_envio = 39Pasa a la 3
3¿Vive a 20 km o menos?costo_envio = 69Se va al else
4elsecosto_envio = 0 y aviso de recoger en tienda
La suma del total no tiene sangría, por eso se hace siempre, sin importar qué opción se eligió.

Pasos

  1. Pedir el total del pedido y la distancia en km.
  2. Revisar en orden la distancia y guardar el costo de envío.
  3. Sumar el pedido más el envío.
  4. Mostrar el costo de envío y el total a pagar.

Código

print("\n*** Nombre 1:    Matricula:     ***")
print("*** Nombre 2:    Matricula:     ***\n")

print("*** Ejercicio 14 Costo de envío ***")

#float() convierte a número con decimales, porque el dinero y los km pueden tener decimales
pedido = float(input("\n¿Cuánto es tu pedido? $"))
#Si el usuario escribe 250, ahora pedido vale 250.0
distancia = float(input("¿A cuántos km vives de la tienda? "))
#Si el usuario escribe 8, ahora distancia vale 8.0

#En cada opción GUARDAMOS el costo de envío en la misma variable
#¿8.0 es menor o igual que 3? False, pasa a la siguiente
if distancia <= 3:
    costo_envio = 0
    print("\n¡Envío gratis!")

#¿8.0 es menor o igual que 10? True, guarda 39 y TERMINA
elif distancia <= 10:
    costo_envio = 39
    print("\nEl envío cuesta $39")

elif distancia <= 20:
    costo_envio = 69
    print("\nEl envío cuesta $69")

#else: vive a más de 20 km
else:
    costo_envio = 0
    print("\nNo hacemos envíos a más de 20 km, recoge tu pedido en tienda")

#Esta parte no tiene sangría, se hace SIEMPRE
#Ahora costo_envio vale 39, esta fórmula dice: total = 250.0 + 39
total = pedido + costo_envio
print(f"Pedido: ${pedido:.2f}")
print(f"Envío: ${costo_envio:.2f}")

Rango en tu videojuego

¿De qué se trata?

En tu videojuego favorito subes de rango según tus puntos. El programa dice en qué rango estás y cuántos puntos te faltan para el siguiente:

  • Menos de 1,000: Bronce (el siguiente es Plata, en 1,000)
  • De 1,000 a 1,999: Plata (el siguiente es Oro, en 2,000)
  • De 2,000 a 2,999: Oro (el siguiente es Diamante, en 3,000)
  • 3,000 o más: Diamante, el rango máximo

La lógica del programa

Ahora empezamos por el rango más alto y vamos bajando. Adentro de cada opción hacemos una cuenta distinta para saber cuántos puntos faltan.

OrdenPreguntaSi es SÍ (True)Si es NO (False)
1¿Tiene 3,000 o más?Diamante, rango máximoPasa a la 2
2¿Tiene 2,000 o más?Oro, faltan 3000 menos sus puntosPasa a la 3
3¿Tiene 1,000 o más?Plata, faltan 2000 menos sus puntosSe va al else
4elseBronce, faltan 1000 menos sus puntos
Adentro de un if, elif o else puede haber varias líneas, hasta cuentas. Todo lo que tenga sangría le pertenece.

Pasos

  1. Pedir los puntos del jugador.
  2. Revisar en orden, del rango más alto al más bajo.
  3. Mostrar el rango y calcular cuántos puntos faltan para el siguiente.

Código

print("\n*** Nombre 1:    Matricula:     ***")
print("*** Nombre 2:    Matricula:     ***\n")

#Si el usuario escribe 2500, ahora puntos vale 2500

#Empezamos por el rango MÁS ALTO
#¿2500 es mayor o igual que 3000? False, pasa a la siguiente
if puntos >= 3000:

#¿2500 es mayor o igual que 2000? True, entra aquí y TERMINA

    faltan = 3000 - puntos

    print("Rango: ORO")
    print(f"Te faltan {faltan} puntos para Diamante")

elif puntos >= 1000:

    print("Rango: PLATA")
    print(f"Te faltan {faltan} puntos para Oro")

#else: tiene menos de 1000
else:
    faltan = 1000 - puntos
    print("Rango: BRONCE")
    print(f"Te faltan {faltan} puntos para Plata")

Reto: arma tu bubble tea

¿De qué se trata?

Vas a armar el pedido completo de un bubble tea. El usuario elige el tamaño y el topping, y el programa calcula el total:

  • Tamaño: 1 = Chico ($55), 2 = Mediano ($70), 3 = Grande ($85). Si escribe otro número, se le da tamaño chico.
  • Topping: 1 = Perlas de tapioca ($15), 2 = Jelly de frutas ($12), 3 = Sin topping ($0). Si escribe otro número, va sin topping.

La lógica del programa

Aquí hay dos decisiones separadas: una para el tamaño y otra para el topping. Son dos bloques de if/elif/else, uno después del otro. Cada bloque guarda un precio en su variable, y al final, afuera de los dos, sumamos.

ParteQué revisaQué guarda
Bloque 1¿Qué tamaño eligió? (1, 2, 3 o else)Guarda precio_bebidaSiempre guarda un precio, porque tiene else
Bloque 2¿Qué topping eligió? (1, 2, 3 o else)Guarda precio_toppingSiempre guarda un precio, porque tiene else
Al finaltotal = precio_bebida + precio_toppingSe calcula siempre
Que el bloque 1 termine no significa que el programa termine. Python sigue con el bloque 2, porque es otra decisión diferente.

Pasos

  1. Mostrar el menú de tamaños, pedir la opción y guardar el precio de la bebida.
  2. Mostrar el menú de toppings, pedir la opción y guardar el precio del topping.
  3. Sumar los dos precios.
  4. Mostrar el resumen del pedido y el total.

Código

print("\n*** Nombre 1:    Matricula:     ***")
print("*** Nombre 2:    Matricula:     ***\n")

print("*** Ejercicio 16 Reto: arma tu bubble tea ***")

#===== DECISIÓN 1: EL TAMAÑO =====

tamano = int(input("Elige tu tamaño: "))
#Si el usuario escribe 2, ahora tamano vale 2

#En cada opción guardamos el nombre y el precio del tamaño
if tamano == 1:
    nombre_tamano = "Chico"
    precio_bebida = 55
#¿2 es igual a 2? True, guarda Mediano y 70, y TERMINA este bloque
elif tamano == 2:
    nombre_tamano = "Mediano"
    precio_bebida = 70
elif tamano == 3:
    nombre_tamano = "Grande"
    precio_bebida = 85
#else: opción no válida, le damos chico
else:
    print("Opción no válida, te damos tamaño chico")
    nombre_tamano = "Chico"
    precio_bebida = 55

#===== DECISIÓN 2: EL TOPPING =====
#Este es OTRO bloque, Python lo revisa aunque el anterior ya haya terminado
print("\n===== TOPPINGS =====")
print("1 = Perlas de tapioca ($15)   2 = Jelly de frutas ($12)   3 = Sin topping ($0)")
topping = int(input("Elige tu topping: "))
#Si el usuario escribe 1, ahora topping vale 1

elif topping == 2:
    nombre_topping = "Jelly de frutas"
    precio_topping = 12
elif topping == 3:
    nombre_topping = "Sin topping"
    precio_topping = 0
#else: opción no válida, va sin topping
else:

    nombre_topping = "Sin topping"
    precio_topping = 0

#===== TOTAL =====
#Sin sangría: se hace SIEMPRE. Esta fórmula dice: total = 70 + 15
total = precio_bebida + precio_topping
#Ahora total vale 85

print("\n===== TU PEDIDO =====")
print(f"Tamaño: {nombre_tamano}  ${precio_bebida}")
print(f"Topping: {nombre_topping}  ${precio_topping}")
print(f"TOTAL: ${total}")

📖 Historia

Vas a programar la pantalla de inicio de sesión de Roblox. El jugador no puede entrar hasta que escriba bien su usuario y su contraseña.

🎯 Tu programa debe

  1. Guardar el usuario correcto y la contraseña correcta.
  2. Pedir el usuario y la contraseña mientras no haya iniciado sesión.
  3. Si el usuario no existe, avisar "Ese usuario no existe".
  4. Si el usuario existe pero la contraseña está mal, avisar "La contraseña es incorrecta".
  5. Cuando los dos estén bien, dar la bienvenida y mostrar "Cargando tus juegos...".

💻 Código

print("Ejercicio 1: Inicia sesión en Roblox") print("Nombre: Escribe aquí tu nombre completo") print("Matrícula: Escribe aquí tu matrícula") print() # Guardamos el usuario y la contraseña correctos usuario_correcto = "gamer17" contrasena_correcta = "roblox123" # Al inicio todavía NO ha iniciado sesión sesion_iniciada = False # Mientras NO haya iniciado sesión, se repite while sesion_iniciada == False: # Pedimos el usuario y la contraseña usuario = input("Usuario: ") contrasena = input("Contraseña: ") # ¿El usuario es IGUAL al correcto? if usuario == usuario_correcto: # Sí existe. Ahora: ¿la contraseña es IGUAL a la correcta? if contrasena == contrasena_correcta: print("✅ ¡Bienvenido,", usuario, "!") # Ya entró: esto hace que el while se detenga sesion_iniciada = True else: print("❌ La contraseña es incorrecta") else: print("❌ Ese usuario no existe") # Esto se ejecuta cuando ya salió del while print("🎮 Cargando tus juegos...")

  1. Guardar el PIN correcto y empezar con 0 intentos.
  2. Pedir el PIN mientras lleve menos de 3 intentos.
  3. Si es correcto, mostrar "Celular desbloqueado" y salir con break.
  4. Si es incorrecto, sumar un intento y decir cuántos le quedan.
  5. Al salir del while: si se acabaron los intentos, mostrar que se bloqueó y dar una pista.
  6. Si sí lo desbloqueó, preguntar si quiere cambiar su PIN.
  7. Si dice que sí, pedir el nuevo PIN y su confirmación mientras no coincidan.

print("Ejercicio 3: Desbloquea tu celular") print("Nombre: Escribe aquí tu nombre completo") print("Matrícula: Escribe aquí tu matrícula") print() # 1. Guardamos el PIN correcto pin_correcto = "2580" # 2. Empezamos con 0 intentos intentos = 0 # 3. Mientras lleve menos de 3 intentos, se repite while intentos < 3: pin = input("🔐 Escribe tu PIN de 4 números: ") # ¿El PIN es IGUAL al correcto? if pin == pin_correcto: print("🔓 Celular desbloqueado") # Ya entró: break lo saca del while break else: # Se equivocó: sumamos 1 intento intentos = intentos + 1 # Calculamos cuántos intentos le quedan restantes = 3 - intentos print("❌ PIN incorrecto. Te quedan", restantes, "intentos") # 4. Ya fuera del while: ¿se acabaron los intentos? if intentos == 3: print("🔒 Celular bloqueado por 30 segundos") print("💡 Pista: son los números de la columna del centro") else: # Sí lo desbloqueó print("📱 Tienes 3 notificaciones nuevas") # 5. Preguntamos si quiere cambiar el PIN cambiar = input("¿Quieres cambiar tu PIN? (s/n): ") if cambiar == "s": # Al inicio los dos PIN todavía NO coinciden coinciden = False # Mientras NO coincidan, se repite while coinciden == False: nuevo = input("Escribe tu nuevo PIN: ") confirmacion = input("Vuelve a escribirlo para confirmar: ") # ¿Los dos son IGUALES? if nuevo == confirmacion: print("✅ Tu PIN se cambió correctamente") coinciden = True else: print("❌ No coinciden, intenta otra vez") else: print("👍 Tu PIN se queda igual")

Ejercicio 4 · La caja registradora de la cafetería

📖 Historia

Eres el cajero. Vas registrando los productos que pide un cliente hasta que escribes "fin". Luego cobras: si el cliente te da menos dinero del total, le pides más hasta que alcance.

🎯 Tu programa debe

  1. Pedir el nombre del producto mientras no escribas "fin".
  2. Por cada producto, pedir el precio y cuántos quiere, y calcular el subtotal.
  3. Ir sumando el total y el número de productos.
  4. Al terminar, mostrar un ticket con la cantidad de productos y el total.
  5. Si el total es de $200 o más, aplicar un descuento de $20.
  6. Pedir con cuánto paga mientras el dinero no alcance.
  7. Mostrar el cambio.

💻 Código

Actividad3_ejercicio4_mimatricula.py
print("Ejercicio 4: La caja registradora de la cafetería") print("Nombre: Escribe aquí tu nombre completo") print("Matrícula: Escribe aquí tu matrícula") print() # Empezamos con el total y los productos en 0 total = 0 productos = 0 # Al inicio todavía NO terminamos de registrar termine = False # Mientras NO hayamos terminado, se repite while termine == False: print("===== Nuevo producto =====") nombre = input("Producto (escribe fin para cobrar): ") # ¿Escribió "fin"? if nombre == "fin": termine = True else: # Pedimos el precio y la cantidad (los convertimos a número) precio = int(input("Precio de " + nombre + ": $")) cantidad = int(input("¿Cuántos quiere? ")) # Calculamos el subtotal de este producto subtotal = precio * cantidad # Lo sumamos al total y contamos los productos total = total + subtotal productos = productos + cantidad print("🧾", cantidad, nombre, "= $", subtotal) print("💰 Llevas $", total) # Ya fuera del while: mostramos el ticket print() print("========== TICKET ==========") print("Productos:", productos) print("Total: $", total) # ¿El total es de 200 o más? if total >= 200: total = total - 20 print("🎉 Descuento de $20 aplicado") print("Total con descuento: $", total) # Pedimos con cuánto paga pago = int(input("¿Con cuánto pagas? $")) # Mientras el pago sea MENOR que el total, no alcanza while pago < total: print("❌ No alcanza. Faltan $", total - pago) pago = int(input("¿Con cuánto pagas? $")) # Ya alcanzó: calculamos el cambio cambio = pago - total print("✅ Pago recibido. Tu cambio es: $", cambio) print("☕ ¡Gracias por tu compra!")
📊 Para tu diagrama: Tiene dos while: registrar productos y cobrar. Los cálculos (subtotal, total y cambio) van en rectángulos.

Ejercicio 10 · Tu playlist en el camión

📖 Historia

Vas en el camión escuchando tu playlist. Hay una canción que siempre saltas y, cuando llegas a tu parada, dejas de escuchar.

🎯 Tu programa debe

  1. Tener una playlist de 6 canciones.
  2. Mostrar la playlist numerada antes de empezar.
  3. Preguntar qué canción quieres saltar y en qué canción llegas a tu parada.
  4. Recorrer la playlist con un for: saltar la canción elegida con continue y detenerse en la parada con break.
  5. Contar cuántas canciones escuchaste.
  6. Si no te bajaste antes, mostrar "Escuchaste toda la playlist" con el else del for.

💻 Código

Actividad3_ejercicio10_mimatricula.py
print("Ejercicio 10: Tu playlist en el camión") print("Nombre: Escribe aquí tu nombre completo") print("Matrícula: Escribe aquí tu matrícula") print() # Nuestra playlist playlist = ["Flowers", "Calm Down", "Ella Baila Sola", "Anti-Hero", "Tití Me Preguntó", "Daylight"] # Mostramos la playlist numerada print("===== 🎧 MI PLAYLIST =====") numero = 1 for cancion in playlist: print(numero, ".", cancion) numero = numero + 1 # Preguntamos qué saltar y dónde bajarse (escríbelas igual que en la lista) saltar = input("¿Qué canción quieres saltar? ") parada = input("¿En qué canción llegas a tu parada? ") # Contador de canciones escuchadas escuchadas = 0 # "Para cada" canción de la playlist... for cancion in playlist: # ¿Es la canción que queremos saltar? if cancion == saltar: print("⏭️ Saltando", cancion) # continue: pasa a la siguiente canción sin escuchar esta continue # Si no la saltamos, la escuchamos print("🎵 Escuchando", cancion) escuchadas = escuchadas + 1 # ¿Es la canción en la que llegamos a la parada? if cancion == parada: print("🚏 ¡Llegaste a tu parada!") # break: dejamos de escuchar break else: # Solo entra aquí si el for terminó SIN break print("🎧 Escuchaste toda la playlist") print("Canciones escuchadas:", escuchadas)
📊 Para tu diagrama: Marca la flecha del continue (regresa a "¿Quedan canciones?") y la del break (va a la salida).

Los clientes de la tienda buscan modelos. Si existe, se les dice que está disponible; si no, se les recomiendan los que sí hay. El buscador sigue abierto hasta que el cliente escribe "salir".

🎯 Tu programa debe

  1. Tener un inventario de 5 modelos.
  2. Con un while True, pedir el modelo a buscar hasta que escriba "salir".
  3. Con un for, buscar el modelo en el inventario. Si lo encuentra, avisar y salir del for con break.
  4. Si no lo encuentra (else del for), avisar y mostrar los modelos que sí hay.
  5. Contar cuántas búsquedas hizo y cuántas encontró.
  6. Al salir, mostrar ese resumen.

💻 Código

Actividad3_ejercicio11_mimatricula.py
print("Ejercicio 11: Buscador de la tienda de sneakers") print("Nombre: Escribe aquí tu nombre completo") print("Matrícula: Escribe aquí tu matrícula") print() # El inventario de la tienda inventario = ["Air Max", "Jordan 1", "Converse", "Samba", "New Balance 550"] # Contadores busquedas = 0 encontrados = 0 # El buscador se repite hasta que el cliente escriba "salir" while True: print() buscado = input("🔍 ¿Qué modelo buscas? (escribe salir para terminar): ") # ¿Escribió "salir"? if buscado == "salir": break # Contamos esta búsqueda busquedas = busquedas + 1 # "Para cada" modelo del inventario... for modelo in inventario: # ¿Este modelo es IGUAL al que busca? if modelo == buscado: print("✅ ¡Sí tenemos", modelo, "!") encontrados = encontrados + 1 # Ya lo encontramos: dejamos de buscar break else: # Solo entra aquí si el for terminó SIN break (no lo encontró) print("❌ No tenemos", buscado) print("👟 Te recomendamos estos modelos:") for modelo in inventario: print(" •", modelo) # Ya salió del buscador: mostramos el resumen print() print("===== RESUMEN =====") print("Búsquedas:", busquedas) print("Encontrados:", encontrados) print("👋 ¡Gracias por visitar la tienda!")
📊 Para tu diagrama: Es un while con un for adentro. Dibuja primero el while y, dentro de su lado Sí, el for.

Ejercicio 12 · Alta de productos con folio

📖 Historia

En tu proyecto CRUD, cada registro necesita una clave. Vas a dar de alta varios productos y el programa le asigna a cada uno un folio automático (SNK1, SNK2...).

🎯 Tu programa debe

  1. Preguntar cuántos productos se van a dar de alta.
  2. Con un for y range, crear el folio de cada uno juntando "SNK" con el número.
  3. Pedir nombre, precio y piezas de cada producto.
  4. Validar con un while que el precio sea mayor que 0.
  5. Calcular cuánto vale cada producto en bodega (precio por piezas) y sumarlo al valor total.
  6. Mostrar la ficha de cada producto y, al final, el valor total del inventario.

💻 Código

Actividad3_ejercicio12_mimatricula.py
print("Ejercicio 12: Alta de productos con folio") print("Nombre: Escribe aquí tu nombre completo") print("Matrícula: Escribe aquí tu matrícula") print() # ¿Cuántos productos vamos a dar de alta? cuantos = int(input("¿Cuántos productos vas a dar de alta? ")) # Aquí sumaremos el valor de todo el inventario valor_total = 0 # "Para cada" número del 1 al total de productos... for numero in range(1, cuantos + 1): # Creamos el folio: str() convierte el número en texto para poder juntarlo folio = "SNK" + str(numero) print() print("📝 Producto con folio", folio) nombre = input("Nombre: ") # Pedimos el precio y lo validamos: mientras sea 0 o menos, se repite precio = int(input("Precio: $")) while precio <= 0: print("❌ El precio debe ser mayor que 0") precio = int(input("Precio: $")) piezas = int(input("Piezas en bodega: ")) # Calculamos cuánto vale este producto en bodega valor = precio * piezas valor_total = valor_total + valor # Mostramos la ficha print("✅ Alta exitosa") print(" Folio:", folio, "· Nombre:", nombre) print(" Precio: $", precio, "· Piezas:", piezas, "· Valor: $", valor) # Ya terminamos todas las altas print() print("===== RESUMEN DEL INVENTARIO =====") print("Productos dados de alta:", cuantos) print("💰 Valor total del inventario: $", valor_total)

Ejercicio 13 · Mis juegos favoritos

Tienes una lista con tus 5 juegos favoritos. Vas a practicar cómo sacar elementos por su casillero y cómo mostrar la lista numerada.

🎯 Tu programa debe

  1. Crear una lista con 5 juegos.
  2. Mostrar el primero, el último (con índice negativo) y el tercero.
  3. Mostrar cuántos juegos hay con len().
  4. Mostrar la lista numerada del 1 al 5 (aunque los casilleros vayan del 0 al 4).
  5. Pedir un número del 1 al 5 y mostrar el juego de ese lugar.

💻 Código

Actividad3_ejercicio13_mimatricula.py
print("Ejercicio 13: Mis juegos favoritos") print("Nombre: Escribe aquí tu nombre completo") print("Matrícula: Escribe aquí tu matrícula") print() # Creamos la lista con 5 juegos juegos = ["Minecraft", "Roblox", "Fortnite", "FIFA", "Among Us"] # Casillero 0: el primero print("🥇 Mi juego número 1:", juegos[0]) # Casillero -1: el último print("🔚 El último de mi lista:", juegos[-1]) # Casillero 2: el tercero (porque empezamos en 0) print("3️⃣ El tercero:", juegos[2]) # len() cuenta cuántos hay print("📦 Tengo", len(juegos), "juegos favoritos") # Mostramos la lista numerada print() print("===== MIS FAVORITOS =====") # range(len(juegos)) nos da los casilleros: 0, 1, 2, 3, 4 for i in range(len(juegos)): # Mostramos i + 1 para que la persona vea del 1 al 5 print(i + 1, ".", juegos[i]) # Pedimos un número del 1 al 5 numero = int(input("Escribe un número del 1 al 5: ")) # La persona cuenta desde 1, pero Python desde 0: por eso le restamos 1 print("🎮 Elegiste:", juegos[numero - 1])
📊 Para tu diagrama: Lo único que se repite es el for que imprime la lista. Todo lo demás son rectángulos uno tras otro.

Ejercicio 14 · Altas en el inventario

📖 Historia

Empiezas con un inventario vacío y vas agregando productos. El sistema no deja agregar un producto vacío ni uno que ya existe.

🎯 Tu programa debe

  1. Empezar con una lista vacía.
  2. Pedir productos mientras no escriba "fin".
  3. Si el producto está vacío, avisar.
  4. Si ya está en la lista (in), avisar que ya existe.
  5. Si todo está bien, agregarlo con append y decir cuántos lleva.
  6. Al final, mostrar el inventario numerado, o "No agregaste productos" si quedó vacío.

💻 Código

Actividad3_ejercicio14_mimatricula.py
print("Ejercicio 14: Altas en el inventario") print("Nombre: Escribe aquí tu nombre completo") print("Matrícula: Escribe aquí tu matrícula") print() # Empezamos con el inventario vacío inventario = [] # Al inicio todavía NO terminamos termine = False while termine == False: nuevo = input("Producto a agregar (escribe fin para terminar): ") # ¿Escribió "fin"? if nuevo == "fin": termine = True # ¿Lo dejó vacío? elif nuevo == "": print("❌ El producto no puede estar vacío") # ¿Ya ESTÁ en el inventario? elif nuevo in inventario: print("⚠️", nuevo, "ya está en el inventario") else: # Todo bien: lo agregamos al final de la lista inventario.append(nuevo) print("✅ Agregado. Llevas", len(inventario), "productos") # Mostramos el inventario print() print("===== INVENTARIO =====") # ¿La lista quedó vacía? if len(inventario) == 0: print("📭 No agregaste productos") else: for i in range(len(inventario)): print(i + 1, ".", inventario[i])
📊 Para tu diagrama: Es un while con varios rombos adentro (if, elif, elif, else). Al final hay un rombo más: "¿la lista está vacía?".

Ejercicio 15 · Bajas en el inventario

📖 Historia

La tienda vendió algunos modelos y ya no los va a tener. Vas a borrar productos del inventario, uno por uno, hasta que el usuario escriba 0.

🎯 Tu programa debe

  1. Empezar con un inventario de 5 modelos.
  2. Con un while True, mostrar el inventario numerado cada vez.
  3. Pedir el número del producto a eliminar (0 para terminar).
  4. Si el número es menor que 1 o mayor que la cantidad de productos, avisar "Ese número no existe".
  5. Si existe, preguntar "¿Seguro que quieres eliminar...? (s/n)".
  6. Si confirma, borrarlo con del; si no, cancelar.
  7. Si el inventario queda vacío, avisar y terminar.
  8. Al final, mostrar cuántos productos quedaron.

💻 Código

Actividad3_ejercicio15_mimatricula.py
print("Ejercicio 15: Bajas en el inventario") print("Nombre: Escribe aquí tu nombre completo") print("Matrícula: Escribe aquí tu matrícula") # El inventario inicial inventario = ["Air Max", "Jordan 1", "Converse", "Samba", "New Balance 550"] while True: # Mostramos el inventario numerado print() print("===== INVENTARIO =====") for i in range(len(inventario)): print(i + 1, ".", inventario[i]) numero = int(input("Número del producto a eliminar (0 para terminar): ")) # ¿Escribió 0? if numero == 0: break # ¿El número es menor que 1? elif numero < 0: print("❌ Ese número no existe") # ¿El número es mayor que la cantidad de productos? elif numero > len(inventario): print("❌ Ese número no existe") else: # El número sí existe. Recuerda: casillero = número - 1 elegido = inventario[numero - 1] confirmar = input("¿Seguro que quieres eliminar " + elegido + "? (s/n): ") if confirmar == "s": # Borramos lo que hay en ese casillero del inventario[numero - 1] print("🗑️", elegido, "fue eliminado") else: print("👍 Baja cancelada") # ¿El inventario quedó vacío? if len(inventario) == 0: print("📭 El inventario quedó vacío") break # Ya salimos del while print() print("Quedaron", len(inventario), "productos en el inventario")
📊 Para tu diagrama: Tiene dos salidas con break: cuando escribe 0 y cuando el inventario queda vacío.

Ejercicio 16 · Cambios en tu playlist

📖 Historia

Quieres cambiar una canción de tu playlist por otra. También puedes mandarla al primer lugar.

🎯 Tu programa debe

  1. Empezar con una playlist de 5 canciones y mostrarla numerada.
  2. Pedir el número de la canción a cambiar.
  3. Validar que el número exista. Si no, avisar.
  4. Mostrar cuál canción se va a cambiar.
  5. Pedir la nueva canción mientras esté vacía.
  6. Si la nueva ya está en la playlist, avisar; si no, reemplazarla.
  7. Preguntar si la quiere mover al primer lugar e intercambiarla con la primera.
  8. Mostrar la playlist final.

💻 Código

Actividad3_ejercicio16_mimatricula.py
print("Ejercicio 16: Cambios en tu playlist") print("Nombre: Escribe aquí tu nombre completo") print("Matrícula: Escribe aquí tu matrícula") print() # La playlist inicial playlist = ["Flowers", "Calm Down", "Ella Baila Sola", "Anti-Hero", "Tití Me Preguntó"] # Mostramos la playlist numerada print("===== 🎧 MI PLAYLIST =====") for i in range(len(playlist)): print(i + 1, ".", playlist[i]) numero = int(input("¿Qué número de canción quieres cambiar? ")) # Validamos que el número exista if numero < 1: print("❌ Ese número no existe") elif numero > len(playlist): print("❌ Ese número no existe") else: # Casillero = número - 1 casillero = numero - 1 actual = playlist[casillero] print("✏️ Vas a cambiar:", actual) # Pedimos la nueva canción: mientras esté vacía, se repite nueva = input("Escribe la nueva canción: ") while nueva == "": print("❌ No puede estar vacía") nueva = input("Escribe la nueva canción: ") # ¿La nueva canción YA ESTÁ en la playlist? if nueva in playlist: print("⚠️", nueva, "ya está en tu playlist") else: # Reemplazamos lo que hay en ese casillero playlist[casillero] = nueva print("✅", actual, "cambió por", nueva) # ¿Quiere mover esta canción al primer lugar? mover = input("¿La quieres mover al primer lugar? (s/n): ") if mover == "s": # Intercambiamos el casillero 0 con el casillero elegido playlist[0], playlist[casillero] = playlist[casillero], playlist[0] print("⬆️ Ahora está en el primer lugar") # Mostramos la playlist final print() print("===== 🎧 PLAYLIST FINAL =====") for i in range(len(playlist)): print(i + 1, ".", playlist[i])
📊 Para tu diagrama: Fíjate en la validación del número (dos rombos) y en el while que no deja la canción vacía.

📖 Historia

El encargado de la tienda quiere consultar el inventario de varias formas: por nombre, por la primera letra o saber cuántos productos hay.

🎯 Tu programa debe

  1. Tener un inventario de 6 modelos.
  2. Con un while True, mostrar un menú de consultas: 1 Buscar por nombre, 2 Buscar por primera letra, 3 Cuántos productos hay, 4 Regresar.
  3. Opción 1: si el modelo está en la lista (in), recorrerla con un for para decir en qué lugar está; si no, avisar.
  4. Opción 2: pedir una letra y, con un for, mostrar todos los modelos que empiezan con esa letra y cuántos son.
  5. Opción 3: mostrar cuántos productos hay con len().
  6. Opción 4: salir con break.

💻 Código

Actividad3_ejercicio17_mimatricula.py
print("Ejercicio 17: Consultas en el inventario") print("Nombre: Escribe aquí tu nombre completo") print("Matrícula: Escribe aquí tu matrícula") # El inventario de la tienda inventario = ["Air Max", "Jordan 1", "Air Force 1", "Converse", "Samba", "Jordan 4"] while True: print() print("===== 🔍 CONSULTAS =====") print("1. Buscar por nombre") print("2. Buscar por primera letra") print("3. ¿Cuántos productos hay?") print("4. Regresar") opcion = input("Elige una opción: ") if opcion == "1": buscado = input("Nombre del modelo (con mayúsculas como en la lista): ") # ¿El modelo ESTÁ en el inventario? if buscado in inventario: # Recorremos los casilleros para saber dónde está for i in range(len(inventario)): if inventario[i] == buscado: print("✅", buscado, "está en el lugar", i + 1) else: print("❌", buscado, "no está en el inventario") elif opcion == "2": letra = input("Escribe la primera letra (en mayúscula): ") encontrados = 0 # "Para cada" producto del inventario... for producto in inventario: # producto[0] es la PRIMERA letra del texto (casillero 0) if producto[0] == letra: print("👟", producto) encontrados = encontrados + 1 # ¿No encontramos ninguno? if encontrados == 0: print("❌ Ningún producto empieza con", letra) else: print("Encontré", encontrados, "productos") elif opcion == "3": print("📦 Hay", len(inventario), "productos en el inventario") elif opcion == "4": print("👋 Regresando...") break else: print("❌ Opción no válida")

  1. Empezar con una lista de 2 productos.
  2. Con un while True, mostrar el menú: Altas, Bajas, Cambios, Consultas, Imprimir y Salir.
  3. Altas: pedir el producto y agregarlo con append (sin dejarlo vacío ni repetido).
  4. Bajas: mostrar la lista numerada, pedir el número, validarlo, confirmar y borrar con del.
  5. Cambios: mostrar la lista, pedir el número, validarlo y reemplazar el producto.
  6. Consultas: decir si un producto está o no en la lista con in.
  7. Imprimir: mostrar la lista numerada y cuántos productos hay (o "vacía").
  8. Salir: terminar con break.
